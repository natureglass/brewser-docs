---
title: Engine Status
description: The remaining gaps in Brewser's hand-written HTML, CSS and DOM engine
---

There is no browser to borrow from on the Switch. Brewser's DOM tree, CSS
cascade, and layout engine are hand-reimplemented in TypeScript (~26K lines)
running on top of the nx.js/V8 + Skia foundation (see
[Architecture](/docs/runtime/architecture)). Overall, that hand-written engine
(DOM, HTML, CSS) covers roughly 70-75% of the "real-world app" surface.

This page is the honest list of what's **not** done yet — the gap lists double
as the contribution roadmap. The last two pillars, WebGL and Audio & Video, are
bridge-backed rather than reimplemented, so they stand higher and their detail
lives on their own pages. If an app or library breaks for you,
[file an issue](https://github.com/natureglass/Brewser/issues) with its name —
real-world breakage reports directly shape what gets built next.

## DOM (~84%)

- `children` still includes text / comment nodes (spec is elements-only); the element-only accessors (`firstElementChild` / `nextElementSibling` / `childElementCount` …) are the correct-behaving alternative
- `outerHTML` has no setter; document / window-level capture listeners aren't wired
- `dialog.showModal()` has no focus trap or Esc-to-close; `setPointerCapture` doesn't reroute events

## HTML (~77%)

- No spec tokenizer / insertion modes: no `<template>` content model, no implicit `<html>` / `<head>` / `<body>` synthesis, comments and doctype are discarded (the parser is otherwise a tolerant tag-soup subset with error recovery)
- No `multipart/form-data` request bodies (binary file upload); urlencoded GET + POST work. No `<datalist>` chrome
- Inline SVG has no patterns, filters, `<image>`, or `<use>` (shapes / paths / `<text>` / gradients / `transform` / `viewBox` are covered)
- `<video>` has no subtitle (`<track>`) tracks; `poster` isn't loaded (a first-frame preview stands in)
- `iframe` `sandbox` / CSP attributes are parsed but not enforced (treated as same-origin)

## CSS (~79%)

- **Cascade:** no `@supports` / `@import` / `@layer` / `@container`; `::placeholder` / `::marker` / `::selection` pseudo-elements unsupported
- **Layout:** no margin collapsing (margins are additive); grid has no `grid-auto-flow: dense` packing, named grid lines, or subgrid; tables have no `border-collapse` / nested-table promotion; `position: sticky` is vertical + page-level only (not inside nested scroll containers)
- **Visual:** no 3D / skew / matrix transforms; `transition` doesn't cover geometric properties (width / height / offsets) or `transform: translate` (those need per-frame relayout); no `clip-path`. On rounded boxes the 3D border styles (groove / ridge / inset / outset) render as a solid stroke; `backdrop-filter` on moving (`fixed` / `sticky`) elements applies blur only (colour functions are skipped there to hold 60fps) and its backdrop excludes lower fixed / modal / scroll-container layers
- **`white-space: pre` / `pre-wrap`** works on `<pre>` and via an inline `style="white-space:pre"`, but not yet when set by a stylesheet class/rule (the parser collapses whitespace before the cascade is known); `pre-line` / `break-spaces` unsupported
- **Units:** physical units (`cm` / `mm` / `in` / `pt` / `pc` / `Q`) are dropped

## WebGL 1 & 2 (~88%)

Bridge-backed, running straight on the Switch's Tegra X1 GPU — not a software
reimplementation. WebGL 1 sits ~92% (the safest target), WebGL 2 ~85% and under
active conformance hardening. Remaining gaps are exhaustive extension coverage
and layered / 3D-texture sampling (GPU-driver-limited). Full extension lists and
proof points: [Graphics](/docs/runtime/graphics).

## Audio & Video (~80%)

Bridge-backed: Web Audio on a hardware-backed graph (~70%), `<audio>` /
`<video>` decode in software via FFmpeg (~85%). Remaining gaps are the Web Audio
effect nodes (filter / convolver / delay / compressor), subtitle tracks, and
hardware video decode. Full node list and codec matrix:
[Audio & Media](/docs/runtime/audio-and-media).

## Summary

| Area | Complete | Biggest missing pieces |
|------|----------|------------------------|
| DOM  | ~84% | `children` elements-only, `outerHTML` setter, document/window capture listeners, `dialog` focus trap |
| HTML | ~77% | spec parser (insertion modes / `<template>`), multipart form uploads, SVG richness (patterns / filters / `<image>` / `<use>`), iframe sandbox enforcement |
| CSS  | ~79% | margin collapsing, 3D / skew / matrix transforms, geometric transitions, `clip-path`, `@supports` / `@layer` |
| [WebGL 1](/docs/runtime/graphics) | ~92% | exhaustive extension coverage |
| [WebGL 2](/docs/runtime/graphics) | ~85% | layered / 3D-texture sampling (GPU-driver-limited), full conformance hardening |
| [Audio & Video](/docs/runtime/audio-and-media) | ~80% | Web Audio effect nodes (filter / convolver / delay / compressor), subtitle tracks, hardware video decode |
