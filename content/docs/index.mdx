---

**Brewser** turns your homebrew-enabled Nintendo Switch into a first-class
web runtime. Browse a catalogue of community-built web apps and games, launch
them instantly, and — if you're a developer — publish your own using nothing
but standard web technology.

## What makes Brewser different

- **Standard Web APIs only.** Apps built for Brewser are plain web apps. If it
  runs on Brewser, it runs in Chrome too.
- **Real hardware access.** WebSerial, WebBluetooth, MIDI, NFC and more, with a
  permission model you control.
- **Built for tinkerers.** Games are welcome, but Brewser is first and foremost
  a playground for makers: dashboards, hardware tools, demos, experiments.
