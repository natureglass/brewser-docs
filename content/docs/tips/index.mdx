Hard-won practical advice for building great Brewser apps.

## Golden rules

1. **Develop in Chrome first.** Brewser implements standard APIs, so your
   fastest iteration loop is a normal browser. Move to the Switch for
   performance tuning and hardware testing.
2. **Design for the couch.** Big touch/click targets, gamepad-first
   navigation, readable text at TV distance.
3. **Keep bundles lean.** Smaller apps download and boot faster on the
   console.
4. **Handle both input worlds.** Touch works only in handheld mode; always
   provide a gamepad path.
