## Web platform

- **WebGL conformance is a work in progress.** Common paths are solid
  (major Three.js scenes run on real hardware); long-tail conformance tests
  still surface gaps. Report anything that behaves differently from Chrome.
- **Unity WebGL 2 exports** are not yet supported (WebGL 1 exports work).
- **Video codec support is limited.** {/* TODO: document exact codec/decoder
  status */}

## Platform

- Touch input is handheld-only (hardware limitation).
- Apps are expected to be self-contained; runtime module resolution is
  local-only.

## Compatibility goal

Everything on this page is a bug or a roadmap item, not a design decision. The
goal is unchanged: if Chrome does it, Brewser should too.
