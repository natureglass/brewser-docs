Notable, user-facing changes to the Brewser runtime. Newest first. App and platform changes that
matter to developers are noted here too.

This page establishes the format; each release gets a dated entry with **Added / Changed / Fixed**
sections as appropriate. Brewser updates itself in place. See
[Installing & Updating](/docs/getting-started/installing) for how updates are delivered and
verified.

**Highlights**

- V8 JavaScript engine (with JIT) on Tegra X1, with Skia 2D and WebGL 1 / WebGL 2 via Mesa.
- Cloud [saves and leaderboards](/docs/features/saves-and-leaderboards) via the drop-in
  [`brewser.js`](/docs/features/brewser-sdk) SDK.
- [Accounts](/docs/features/accounts) with Google device-code sign-in on the console.
- Signed, forward-only [self-update](/docs/getting-started/installing).
- Broad audio/video codec support ([Audio & Media](/docs/runtime/audio-and-media)).
