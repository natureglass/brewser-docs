## Reporting bugs

Found a runtime bug or a web API that misbehaves? Include:

1. What you expected (ideally: what Chrome does)
2. What Brewser did instead
3. A minimal repro — a small HTML/JS snippet is perfect

[Report a bug on GitHub](https://github.com/natureglass/Brewser/issues).

## Requirements

- Nintendo Switch with custom firmware (Atmosphère) — see the
  [NH Switch Guide](https://switch.hacks.guide/) if you're starting from zero
- Network connection for the catalogue
